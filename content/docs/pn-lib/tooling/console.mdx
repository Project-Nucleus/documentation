---
title: Console
description: Typed command registration with argument parsing.
---

Wraps `RegisterCommand` with positional argument parsing and type casting. Auto-registers a `<resourceName>:commands` command that lists all registered commands.

### lib.console.register

```lua
lib.console.register(name, args, handler, restricted?)
```

**Parameters**
```lua
name        : string
args        : {
    name     : string,                           -- argument name
    type?    : 'string' | 'number' | 'boolean',  -- cast target (default 'string')
    validate?: fun(v) -> boolean, string?,        -- optional validator
}[]
handler     : fun(source: integer, args: table)
restricted? : boolean
```

Args are cast to their declared types before `handler` is called.

---

### lib.console.unregister

```lua
lib.console.unregister(name: string)
```

Removes the handler record. Does not un-register from FiveM.

---

### lib.console.list

```lua
lib.console.list() -> string[]
```

Returns a sorted list of registered command names.

**Returns** `string[]`.

---

## Example

```lua
lib.console.register('giveitem', {
    { name = 'target', type = 'number' },
    { name = 'item',   type = 'string' },
    { name = 'count',  type = 'number' },
}, function(source, args)
    print(args.target, args.item, args.count)
end, true)
```
