---

Wraps functions with preconditions and postconditions. In production (`snowy_prod = true`), `wrap` returns the original function unchanged.

### lib.contracts.wrap

```lua
lib.contracts.wrap(fn, pre, post?) -> fun(...) -> any
```

**Parameters**
```lua
fn   : fun(...) -> any
pre  : fun(...)
post?: fun(result, ...)
```

Returns a wrapped function that calls `pre(...)`, then `fn(...)`, then `post(result, ...)`.

**Returns** `fun(...) -> any` — the wrapped function.

---

### lib.contracts.schema

```lua
lib.contracts.schema(schema: string[]) -> fun(...)
```

Returns a precondition function that checks each argument's type against the corresponding entry in `schema`. Errors if any type mismatches.

**Returns** `fun(...)` — a precondition checker.

---

## Example

```lua
local safeAdd = lib.contracts.wrap(
    function(a, b) return a + b end,
    lib.contracts.schema({ 'number', 'number' }),
    function(result)
        lib.assertions.assert(result > 0, 'result must be positive')
    end
)

print(safeAdd(2, 3)) -- 5
```
