---
title: Crypto
description: Hashing and token generation.
---

### lib.crypto.jenkins

```lua
lib.crypto.jenkins(s: string) -> integer
```

Jenkins one-at-a-time hash. Result masked to 32 bits.

**Returns** `integer`.

---

### lib.crypto.murmur3

```lua
lib.crypto.murmur3(s: string, seed?: integer) -> integer
```

MurmurHash3 (32-bit). Accepts an optional seed.

**Returns** `integer`.

---

### lib.crypto.token

```lua
lib.crypto.token(bytes?: integer) -> string
```

Generates a random hex string. `bytes` defaults to 16, producing a 32-character hex token.

**Returns** `string` — hex token.

---

## Example

```lua
local hash = lib.crypto.jenkins('hello')
print(hash) -- integer

local token = lib.crypto.token(24) -- 48-char hex
print(token)
```
