## `lib.validation.check`

```lua
lib.validation.check(data: table, schema: table<string, string|fun>) -> boolean, string?
```

Validates `data` against `schema`. Each schema entry is either a type-name string or a `fun(v): boolean, string?` validator. Returns `false, errorMessage` on the first failure.

## `lib.validation.assert`

```lua
lib.validation.assert(data: table, schema: table)
```

Same as `check` but errors on failure instead of returning.

## Built-in rule factories

### `lib.validation.rules.range`

```lua
lib.validation.rules.range(min: integer, max: integer) -> fun
```

Returns a validator that checks the value is within `[min, max]`.

### `lib.validation.rules.maxlen`

```lua
lib.validation.rules.maxlen(max: integer) -> fun
```

Returns a validator that checks a string's length is `<= max`.

### `lib.validation.rules.enum`

```lua
lib.validation.rules.enum(t: table) -> fun
```

Returns a validator that checks the value is one of the values in `t`.

## Example

```lua
local schema = {
    name   = 'string',
    age    = lib.validation.rules.range(0, 120),
    gender = lib.validation.rules.enum({ 'm', 'f', 'other' }),
}

local ok, err = lib.validation.check({
    name   = 'John',
    age    = 25,
    gender = 'm',
}, schema)

print(ok) -- true
```
