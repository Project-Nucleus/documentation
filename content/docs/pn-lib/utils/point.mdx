---
title: Point
description: Spherical proximity trigger with optional per-frame callback.
---

<Callout type="info">Client-side only.</Callout>

Grid-accelerated proximity point. Fires enter/exit when the player crosses the distance threshold, and an optional `onNearby` callback while inside.

Points created via `lib.point` are automatically re-created when `pn_lib` restarts.

### lib.point.new

```lua
lib.point.new(def) -> Point
```

**Parameters**
```lua
def: {
    coords         : vector3,          -- world position
    distance       : number,           -- trigger radius
    onEnter?       : fun(self),        -- fires when player enters
    onExit?        : fun(self),        -- fires when player exits
    onNearby?      : fun(self, dist),  -- fires while inside; receives current distance
    nearbyInterval?: integer,          -- onNearby interval in ms (default 100, 0 = every frame)
    debug?         : boolean,          -- draw debug sphere (default false)
}
```

**Returns** `Point`.

---

### Point:remove

```lua
Point:remove()
```

Unregisters the point. Stops all callbacks.

---

## Example

```lua
local point = lib.point.new({
    coords   = vector3(100.0, 200.0, 30.0),
    distance = 10.0,
    onEnter  = function(self)
        lib.ui.showTextUI('Press E to interact')
    end,
    onExit   = function(self)
        lib.ui.hideTextUI()
    end,
    onNearby = function(self, dist)
        -- runs every 100ms while inside
    end,
})
```
