---
title: Zone
description: Polygon, box, and sphere trigger zones.
---

<Callout type="info">Client-side only.</Callout>

Zones fire `onEnter(self)` and `onExit(self)` as the local player crosses the boundary. Checks run every 100 ms using a grid-accelerated loop. Debug wireframes render when `snowy_debug` is `true` or the zone has `debug = true`.

Zones created via `lib.zone` are automatically re-created when `pn_lib` restarts.

### lib.zone.box

```lua
lib.zone.box(def) -> Zone
```

**Parameters**
```lua
def: {
    coords  : vector3,     -- center of the box
    size    : vector3,     -- half-extents
    heading?: number,      -- rotation in degrees (default 0)
    onEnter?: fun(self),   -- fires on entry
    onExit? : fun(self),   -- fires on exit
    debug?  : boolean,     -- draw wireframe (default false)
}
```

**Returns** `Zone`.

---

### lib.zone.sphere

```lua
lib.zone.sphere(def) -> Zone
```

**Parameters**
```lua
def: {
    coords  : vector3,
    radius  : number,
    onEnter?: fun(self),
    onExit? : fun(self),
    debug?  : boolean,
}
```

**Returns** `Zone`.

---

### lib.zone.poly

```lua
lib.zone.poly(def) -> Zone
```

2D polygon with Z extents. Uses ray-casting for the inside test.

**Parameters**
```lua
def: {
    points  : vector2[],   -- polygon vertices
    minZ    : number,
    maxZ    : number,
    onEnter?: fun(self),
    onExit? : fun(self),
    debug?  : boolean,
}
```

**Returns** `Zone`.

---

### Zone:isInside

```lua
Zone:isInside(x: number, y: number, z: number) -> boolean
```

Tests whether the coordinate is inside the zone.

**Returns** `boolean`.

---

### Zone:remove

```lua
Zone:remove()
```

Unregisters the zone. Stops all callbacks.

---

## Example

```lua
local zone = lib.zone.box({
    coords  = vector3(100.0, 200.0, 30.0),
    size    = vector3(5.0, 5.0, 3.0),
    onEnter = function(self)
        print('Entered zone')
    end,
    onExit  = function(self)
        print('Left zone')
    end,
})

zone:remove()
```
