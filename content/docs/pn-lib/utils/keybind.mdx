title: Keybind
description: Client-side key mapping.

<Callout type="info">Client-side only.</Callout>

Keybinds created via `lib.keybind` are automatically re-registered when `pn_lib` restarts.

### lib.keybind.add

```lua
lib.keybind.add(opts) -> { disable: fun(self, val: boolean) }
```

Registers a key binding. Returns a handle.

**Parameters**
```lua
opts: {
    name?       : string,  -- unique identifier
    description?: string,  -- shown in key bindings settings
    defaultKey? : string,  -- default key (e.g. 'E', 'F6')
    onPressed   : fun(),   -- called when the key is pressed
}
```

**Returns** `{ disable: fun(self, val: boolean) }` — handle.

---

## Handle methods

### handle:disable

```lua
handle:disable(val: boolean)
```

Enables or disables the keybind at runtime.

---

## Example

```lua
local bind = lib.keybind.add({
    name        = 'openInventory',
    description = 'Open your inventory',
    defaultKey  = 'F2',
    onPressed   = function()
        openInventory()
    end,
})

bind:disable(true)  -- disable
bind:disable(false) -- re-enable
```
