---
title: String
description: String utilities.
---

## `lib.string.trim`

```lua
lib.string.trim(s: string) -> string
```

Strips leading and trailing whitespace.

## `lib.string.split`

```lua
lib.string.split(s: string, sep: string) -> string[]
```

Splits on a separator character.

## `lib.string.sanitize`

```lua
lib.string.sanitize(s: string, pattern?: string) -> string
```

Removes characters matching `pattern`. Default pattern strips control characters and null bytes.

## `lib.string.startsWith`

```lua
lib.string.startsWith(s: string, prefix: string) -> boolean
```

## `lib.string.endsWith`

```lua
lib.string.endsWith(s: string, suffix: string) -> boolean
```

## `lib.string.truncate`

```lua
lib.string.truncate(s: string, max: integer, suffix?: string) -> string
```

Truncates to `max` characters. Appends `suffix` (default `'...'`) when truncated.

## `lib.string.padLeft`

```lua
lib.string.padLeft(s: string, len: integer, char?: string) -> string
```

Left-pads to `len` with `char` (default `' '`).

## `lib.string.padRight`

```lua
lib.string.padRight(s: string, len: integer, char?: string) -> string
```

Right-pads to `len` with `char`.

## `lib.string.capitalize`

```lua
lib.string.capitalize(s: string) -> string
```

Uppercases the first character.

## `lib.string.count`

```lua
lib.string.count(s: string, pattern: string) -> integer
```

Counts non-overlapping occurrences of `pattern`.
