---
title: Lifecycle
description: Thread-based timing primitives.
---

## `lib.lifecycle.onReady`

```lua
lib.lifecycle.onReady(fn: fun())
```

Spawns a thread that waits one tick then calls `fn`. Use this to defer initialization until the first frame.

## `lib.lifecycle.tick`

```lua
lib.lifecycle.tick(ms: integer, fn: fun(dt: integer)) -> fun()
```

Spawns a loop that waits `ms` and calls `fn(dt)` where `dt` is the actual elapsed ms. Returns a cancel function.

## `lib.lifecycle.frame`

```lua
lib.lifecycle.frame(fn: fun()) -> fun()
```

Spawns a zero-wait loop calling `fn` every frame. Returns a cancel function.

## Example

```lua
lib.lifecycle.onReady(function()
    print('Resource ready')
end)

local cancelTick = lib.lifecycle.tick(500, function(dt)
    print('Half-second tick, actual dt:', dt)
end)

local cancelFrame = lib.lifecycle.frame(function()
    -- runs every frame
    DrawMarker(...)
end)
```
