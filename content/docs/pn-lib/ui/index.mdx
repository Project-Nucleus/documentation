---
title: UI
description: pn_ui card system wrapper.
---

<Callout type="info">Client-side only.</Callout>

`lib.ui` wraps the `pn_ui` export-based card system. Focus is managed automatically: menus, dialogs, and custom cards grab NUI focus when shown and release it when the last such card is hidden.

Cards are identified by string IDs. Pass your own `id` to control a card later, or omit it to get an auto-generated one.

## Cards

### lib.ui.showMenu

```lua
lib.ui.showMenu(opts) -> string
```

**Parameters**

```lua
opts: {
    title?    : string,
    subtitle? : string,
    items     : { id: string, label: string, description?: string, icon?: string, disabled?: boolean, arrow?: boolean, separator?: boolean }[],
    position? : string,   -- default: 'center-right'
    closeable?: boolean,
    id?       : string,
}
```

**Returns** `string` — card ID.

---

### lib.ui.showNotification

```lua
lib.ui.showNotification(opts) -> string
```

**Parameters**

```lua
opts: {
    title    : string,
    message? : string,
    level?   : 'info' | 'success' | 'warning' | 'error',  -- default: 'info'
    duration?: number,
    position?: string,  -- default: 'top-right'
    id?      : string,
}
```

**Returns** `string` — card ID.

---

```lua
    position?  : string,  -- default: 'center'
    id?        : string,

```

**Returns** `string` — card ID.

---

### lib.ui.showProgress

```lua
lib.ui.showProgress(opts) -> string
```

**Parameters**

```lua
opts: {

    cancelable?: boolean,
    position? : string,   -- default: 'bottom-center'
    id?       : string,

```

**Returns** `string` — card ID. Update `value` via `lib.ui.updateCard`.

## Lifecycle

### lib.ui.hideCard

```lua
lib.ui.hideCard(id: string)
```

Hides a specific card and releases its focus slot.

---

### lib.ui.hideAll

```lua
lib.ui.hideAll()
```

Hides every card shown through `lib.ui` and drops focus.

---

### lib.ui.updateCard

```lua
lib.ui.updateCard(id: string, patch: table)
```

Sends a partial update to a visible card. Use this to update `value` on a progress card.

---

### lib.ui.setFocus

```lua
lib.ui.setFocus(hasFocus: boolean, hasCursor: boolean)
```

Manually sets NUI focus. Prefer letting `lib.ui` manage focus automatically.

---

```lua
lib.ui.showTextUI(text: string, opts?: { position?: string })
```

## Blocking dialogs

These yield the calling coroutine until the user responds.

### lib.ui.inputDialog

```lua
lib.ui.inputDialog(title: string, fields: table[]) -> any[]?
```

**Parameters**

```lua
title  : string
fields : {
    type       : 'input' | 'number' | 'select' | 'checkbox',
    label      : string,
    required?  : boolean,
    default?   : any,
    placeholder?: string,
    min?       : number,
    max?       : number,
    options?   : table[],
}[]
```

**Returns** `any[]` — values in field order, or `nil` if cancelled.

---

### lib.ui.alertDialog

```lua
lib.ui.alertDialog(opts) -> 'confirm' | nil
```

**Parameters**

```lua
opts: {
    header? : string,
    title?  : string,
    content?: string,
    cancel? : boolean,
}
```

**Returns** `'confirm'` or `nil`.

---

### lib.ui.progressBar

```lua
lib.ui.progressBar(opts) -> boolean
```

Blocks until complete or cancelled.

**Parameters**

```lua
opts: {
    duration  : number,  -- ms, default: 5000
    label?    : string,
    canCancel?: boolean,
    anim?     : { dict: string, clip: string },
}
```

**Returns** `true` on completion, `false` on cancel.

## Context menus

### lib.ui.registerContext

```lua
lib.ui.registerContext(ctx)
```

**Parameters**

```lua
ctx: {
    id      : string,
    title   : string,
    options : {
        title      : string,
        description?: string,
        icon?      : string,
        disabled?  : boolean,
        arrow?     : boolean,
        separator? : boolean,
        onSelect?  : fun(),
    }[],
}
```

Icons accept FontAwesome names (`trash`, `pen`, `plus`, etc.) or `FiXxx` react-icons names directly.

---

### lib.ui.showContext

```lua
lib.ui.showContext(id: string)
```

Opens the registered context menu. Closes any currently active one first.

## Example

```lua
lib.ui.showNotification({
    title   = 'Payment received',
    message = '$500 added to your account',
    level   = 'success',
})

local completed = lib.ui.progressBar({
    duration  = 5000,
    label     = 'Searching...',
    canCancel = true,
    anim      = { dict = 'missfam4_piano', clip = 'base' },
})

local values = lib.ui.inputDialog('Edit player', {
    { type = 'input',  label = 'Name',   required = true },
    { type = 'number', label = 'Amount', min = 0, max = 10000 },
})
if values then
    print(values[1], values[2])
end

lib.ui.registerContext({
    id      = 'myMenu',
    title   = 'Actions',
    options = {
        { title = 'Repair',  icon = 'car',   onSelect = function() repairVehicle() end },
        { title = 'Dismiss', icon = 'xmark', onSelect = function() lib.ui.hideContext() end },
    },
})

lib.ui.showContext('myMenu')
```
