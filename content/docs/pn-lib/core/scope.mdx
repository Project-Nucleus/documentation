---
title: Scope
description: Lifecycle container for listeners and cleanup callbacks.
---

Groups listeners and cleanup functions under one object. Calling `destroy()` removes everything at once.

## `lib.scope.create`

```lua
lib.scope.create() -> Scope
```

Creates a new scope. Scopes created via `lib.scope.create` are automatically destroyed when the owning resource stops.

## Methods

### `Scope:track`

```lua
Scope:track(listener: Listener) -> Listener
```

Adds a Listener to be removed on `destroy()`. Returns the listener.

### `Scope:onDestroy`

```lua
Scope:onDestroy(fn: fun())
```

Queues an arbitrary cleanup function to run when the scope is destroyed.

### `Scope:destroy`

```lua
Scope:destroy()
```

Calls `remove()` on all tracked listeners and runs all cleanup functions.

## Example

```lua
local scope = lib.scope.create()

local remove = AddEventHandler('someEvent', function()
    print('event fired')
end)

scope:onDestroy(remove)
scope:onDestroy(function()
    print('scope cleaned up')
end)

-- later
scope:destroy()
```
