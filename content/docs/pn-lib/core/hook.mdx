---
title: Hook
description: Middleware pipeline wrapping a Dispatcher.
---

Runs ordered middleware tiers (`before` → `normal` → `after`) before dispatching to subscribers.

## `lib.hook.new`

```lua
lib.hook.new(dispatcher?: Dispatcher) -> Hook
```

Creates a hook. If no dispatcher is provided, a fresh one is created internally.

## Methods

### `Hook:use`

```lua
Hook:use(priority: 'before' | 'normal' | 'after', handler: fun(next: fun(...), ...))
```

Registers a middleware in the given tier. The handler receives `next` as its first argument and must call it to continue the chain.

### `Hook:on`

```lua
Hook:on(event: string, handler: fun(...)) -> fun()
```

Delegates to the underlying dispatcher's `on`. Returns an unsubscribe function.

### `Hook:dispatch`

```lua
Hook:dispatch(event: string, ...)
```

Builds the full middleware chain and executes it. Dispatches to subscribers after all middleware has run.

## Example

```lua
local h = lib.hook.new()

h:use('before', function(next, ...)
    print('before middleware')
    next(...)
end)

h:use('after', function(next, ...)
    next(...)
    print('after middleware')
end)

h:on('save', function(data)
    print('saving', data)
end)

h:dispatch('save', 'my data')
-- before middleware
-- saving my data
-- after middleware
```
